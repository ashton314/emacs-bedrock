# Emacs Bedrock

A foundation for a better Emacs experience

## Synopsis

An *extremely* minimal Emacs starter kit that uses no external packages by default. Intended to be copied once and then modified as the user grows in knowledge and power.

Requires Emacs 31.1 or newer.

⁂

As of 2024-02-07, Bedrock is officially hosted on [Codeberg](https://codeberg.org/ashton314/emacs-bedrock). This repository exists as a place to star Bedrock. Please copy/clone from the official Codeberg-hosted repository, and open issues there if you find any bugs. Thank you.
